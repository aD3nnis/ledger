# ledger

A small payments ledger built feature by feature with [Claude Code](https://claude.com/claude-code), as a public record of a spec-first, test-first workflow.

Each feature leaves a trail you can follow:
- **SPEC** in [`docs/specs/`](docs/specs/) — what it must do, with testable "done" lines
- **Plan** in [`docs/plans/`](docs/plans/) — the checklist, edited by a human before work starts
- **Decisions** in [`docs/decisions/`](docs/decisions/) — ADRs for choices worth explaining
- **Pull request** — red→green test output, end-to-end screenshot, review findings, green CI
- **Build log** in [`docs/build-log/`](docs/build-log/) — dead ends and final shape

Working rules for humans and Claude: [`CLAUDE.md`](CLAUDE.md) and [`docs/standards.md`](docs/standards.md).
